# 패턴 구간 추천 (메인 기능)

## 무엇을 하나

매일 미국 장 마감 후 나스닥 상장 보통주 전체를 훑어서, 피보나치 스윙 되돌림 **매수 검토 구간**에
들어온 종목을 보여준다. "반드시 사라"가 아니라 "이 패턴 기준으로 검토할 자리"라는 뜻이다.
투자 결정은 사용자가 차트를 직접 확인하고 내린다.

추천한 내용은 전부 기록되고, 이후 시세로 자동 채점된다. 기록이 쌓이면 "이 도구가 실제로 맞았나"가 숫자로 드러난다.

## 규칙

| 항목 | 내용 |
|---|---|
| 대상 | 나스닥 상장 보통주 (ETF·워런트·우선주·유닛 제외) 중 주가 $5 이상, 최근 60일 하루 거래대금 중앙값 $10M 이상 |
| 스윙 | 일봉: 저점에서 +30% 이상 오른 고점 / 주봉: +50% 이상 |
| 매수 구간 | 0.786 ~ 0.886 (절반씩 분할) |
| 손절 | 1 (스윙 저점) 이탈 |
| 1차 목표 | 스윙의 0.5 |
| 2~4차 목표 | 고점과 매수 후 바닥으로 다시 그은 피보나치의 0.5 / 0.786 / 1.31 |
| 추천 조건 | 최근(일봉 10봉, 주봉 3봉) 안에 구간에 들어왔고, 아직 1차 목표·손절 전이며, 현재가가 구간 상단 +2% 이내 |

규칙은 `quant_core/pattern_setup.py` 한 곳에만 있고, 스캐너와 채점이 모두 이것을 쓴다.
과거 검증 엔진(`scripts/fib_strategy_backtest.py`)과 진입 시점이 완전히 일치하는지 테스트로 확인한다
(`tests/test_pattern_setup.py`).

## 화면

- 한 종목 = 카드 한 장. 매수 구간 · 손절 · 1차 목표 세 숫자만 크게.
- 배지: 주봉/일봉, 구간 안/위/아래, "일봉도 구간"(주봉·일봉 모두 해당 시).
- 참고 근거: RSI 과매도, RSI 상승 다이버전스, 하락 빗각 돌파, 200일선 위, 반전 캔들 — **해당할 때만** 표시.
  과거 검증에서 이 지표들은 확률을 유의하게 올리지 못했으므로 점수에 넣지 않는다.
- 자세히(접힘): 스윙 날짜, 2~4차 목표, 과거 통계.
- 곧 구간에 들어올 종목, 추천 기록은 접어서 아래에.

## 채점 (전방 검증)

- 추천일 **다음 거래일부터**만 본다. 추천일 종가(0.786보다 높으면 0.786 가격)에 절반, 0.886에 닿으면 나머지 절반을 샀다고 가정.
- **적중** = 1차 목표에 손절보다 먼저 도달. **손절** = 그 반대. 결과가 나기 전은 진행 중.
- 규칙 전체(4단계 익절)의 수익률과 같은 기간 QQQ 수익률도 함께 기록.
- 추천 당시 값은 이후 바꾸지 않는다 (`pattern_history.json`).

## 무작위 비교군

적중률만으로는 잘한 건지 알 수 없다. 상승장에서는 아무 종목이나 사도 1차 목표에 잘 닿기 때문이다.
그래서 진짜 추천 1건마다 **같은 날 무작위 종목 3개**에 같은 모양의 가격표를 붙여 함께 기록·채점한다
(`pattern_placebo.json`).

- 가격표: 진짜 추천의 스윙 저점·고점을 비교군 종목의 추천일 종가에 비율 그대로 옮긴다.
  매수 구간·손절·목표까지의 거리(%)가 같다.
- 변동성이 진짜 추천의 0.67~1.5배인 종목에서만 뽑는다. 저변동 종목에 같은 % 손절·목표를 붙이면
  어느 쪽에도 잘 닿지 않아 비교가 기운다.
- 추천 ID로 무작위 시드를 고정한다. 다시 만들어도 같은 종목이 뽑히므로 결과를 보고 고를 수 없다.
- 화면 상단: "같은 날 무작위 종목 비교군 N% → 차이 ±Np". 진짜 추천이 결과 난 날짜의 비교군끼리 비교한다.

## 실적 발표일

- 추천 종목마다 다음 실적 발표 예정일을 조회한다(yfinance, 실패해도 스캔은 계속).
- **14일 이내**면 카드에 "실적 발표 D-n" 경고 배지. 매수 구간은 손절선과 가까워 발표 직후 갭이
  곧바로 손절로 이어질 수 있다.
- 예정일이 없으면 비워 둔다(지난 발표일을 '다음'으로 표시하지 않음).
- 추천 기록에 발표일을 남겨, 나중에 '실적 직전 추천'의 성적을 따로 볼 수 있다.

## 새 추천 알림

새로 매수 구간에 들어온 종목이 있을 때만 보낸다. 이미 알린 종목은 다시 보내지 않는다.
설정은 GitHub 저장소 → Settings → Secrets and variables → Actions → **New repository secret**.
아무것도 넣지 않으면 알림 없이 스캔만 돈다.

### 텔레그램 (권장)

1. 텔레그램에서 `@BotFather` 대화 → `/newbot` → 이름 입력 → **토큰**을 받는다.
2. 만든 봇과 대화를 열고 아무 메시지나 한 번 보낸다.
3. 브라우저에서 `https://api.telegram.org/bot<토큰>/getUpdates` 를 열어
   `"chat":{"id": 숫자` 의 숫자를 확인한다(**채팅 ID**).
4. Secrets 추가: `TELEGRAM_BOT_TOKEN` = 토큰, `TELEGRAM_CHAT_ID` = 채팅 ID

### 메일 (Gmail)

1. Google 계정 → 보안 → 2단계 인증 사용 → **앱 비밀번호** 생성 (일반 비밀번호는 쓰지 말 것).
2. Secrets 추가: `SMTP_USER` = 보내는 Gmail 주소, `SMTP_PASSWORD` = 앱 비밀번호,
   `ALERT_EMAIL_TO` = 받을 주소(여러 개면 쉼표로)

### 공통 (선택)

`APP_URL` = Streamlit 앱 주소. 알림 끝에 링크로 붙는다.

토큰·비밀번호는 코드와 로그에 남지 않는다. 전송이 실패해도 예외 종류만 로그에 적는다.

## 과거 통계의 의미와 한계

화면의 "과거 같은 조건에서 1차 목표 먼저 도달 46~48% (아무 때나 샀을 때 38~39%)"는
S&P 500 과거 구성종목(2013~2026) 백테스트 결과다 (docs/FIB_STRATEGY_STUDY.md).

- 효과의 원인은 피보나치 비율이 아니라 "크게 오른 종목이 깊게 눌렸을 때 산다"는 진입 조건이다.
- 규칙 전체는 같은 기간 SPY를 그냥 보유한 것보다 수익이 낮았다.
- 나스닥 중소형주는 과거 검증 대상에 없었다. 이 도구의 추천 기록이 그 검증 역할을 한다.
- 1차 목표 도달 확률 차이(약 6~10%p)는 수년치 기록이면 판정할 수 있는 크기다.
