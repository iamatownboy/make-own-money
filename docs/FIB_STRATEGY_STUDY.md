# 피보나치 스윙 매매 규칙 검증 (매수 쪽)

재현:
```bash
python scripts/fib_strategy_backtest.py --market crypto --tf 4h --swing 0.30
python scripts/fib_strategy_backtest.py --market stocks --tf 1w --swing 0.50
python scripts/fib_strategy_backtest.py --market stocks --tf 1w --swing 0.50 --entry 0.70 0.80   # 비피보나치 대조
python scripts/fib_strategy_backtest.py --market stocks --tf 1w --swing 0.50 --hold-only --max-bars 52  # 매도 방식 대조
```
데이터는 `data/cache/`에 캐시한다(재생성 가능, git 제외). 코인은 Binance 공개 데이터(data-api.binance.vision),
주식은 과거 S&P 500 구성종목의 yfinance 수정 OHLC.

## 검증한 규칙

| 단계 | 규칙 |
|---|---|
| 스윙 | 저점(1) → 고점(0), 상승폭 기준 이상. 그 시점까지의 봉만 사용 |
| 매수 | 0.786에 절반, 0.886에 절반 분할 지정가 |
| 손절 | 1(원래 저점) 이탈 시 전량 (장중 터치) |
| 익절 | 25%씩: 원래 피보나치 0.5 → 고점·바닥 재작도 0.5 → 0.786 → 1.31 |

봉 안의 순서가 불분명하면 손절을 먼저 처리(보수적). 갭은 시가 체결. 수수료 코인 0.1%, 주식 0.05% (편도).
엔진은 손계산 가능한 가상 차트로 검증했다(수익률·R 값 소수점 셋째 자리까지 일치).

## 대조군 (위약)

실제 거래 1건마다 같은 종목의 무작위 날짜 5개에 **같은 비율의 가격표**(0.886 추가 매수, 1 손절, 4단계 익절)를
붙이고, 진입도 실제와 같은 **지정가** 방식으로 체결시켜 똑같이 관리했다. 차이 = "스윙 되돌림 자리에서 샀다"의 순수 효과.

판정은 신뢰구간을 **종목 단위**와 **진입 월 단위** 두 방식으로 묶어 모두 0을 넘을 때만 인정했다.
(주식은 시장 전체가 같이 움직여 같은 달 신호가 사실상 한 사건이기 때문)

## 데이터 정제 과정에서 발견·수정한 문제

- **티커 재사용**: 파산한 SBNY(시그니처은행), 합병된 STI(선트러스트)의 티커를 다른 회사가 쓰면서 yfinance가
  엉뚱한 시세를 반환 → 578배 수익 같은 가짜 거래 발생. **각 종목을 실제 S&P 500 구성종목이던 기간에만 매수**하고,
  편출 6개월 뒤 시세는 버리도록 수정.
- **재상장 코인**: LUNA·FTT는 폭락 후 같은 이름으로 재상장 → 시세가 오래 끊긴 지점에서 별도 자산으로 분리.
- **위약 체결 방식**: 처음엔 위약이 종가 매수여서 장중 눌림에 지정가로 사는 실제 규칙이 구조적으로 유리했음 → 지정가로 통일.

종목 묶음 기준으로 유의하다.

## 결과 2: 피보나치 비율이 원인인가 (주식 주봉, 스윙 +50%)

| 매수 구간 | 무작위 대비 거래당 | 1차 익절 도달 차이 | SPY 대비 |
|---|---:|---:|---:|
| 0.786 / 0.886 (피보나치) | +5.43%p | +10.1%p | −1.63%p |
| 0.70 / 0.80 | +5.36%p | +9.8%p | −2.87%p |
| 0.60 / 0.70 | +4.85%p | +7.0%p | −3.90%p |

**비피보나치 비율로 사도 우위가 거의 같다.** 효과의 원인은 피보나치 비율이 아니라
"크게 오른 종목이 되돌림할 때 산다"는 진입 자체다. (docs/FIB_LEVEL_STUDY.md의 결론과 일치)

## 결과 3: 매도 방식이 원인인가 (같은 자리에서 사서 손절·익절 없이 보유)

| 시장 | 보유 | 무작위 대비 | 벤치마크 대비 | 비고 |
|---|---|---:|---:|---|
| 주식 1w, +50% | 26주 | +8.11%p | +0.27%p | |
| 주식 1w, +50% | 52주 | +20.97%p | +6.41%p | 월 묶음 시 [−1.79, +13.01], 상위 30건(4%) 제외 시 +0.07%p |
| 코인 1w, +50% | 52주 | +135%p | +120%p | **중앙값 −20.8%**, 전반 +290%p / 후반 −17%p |
| 코인 1d, +50% | 180일 | −11.05%p | +14.27%p | 중앙값 −16.0%, 후반 −48%p |

주식에서 "버티면 SPY를 이긴다"는 결과는 **견고하지 않다.** 같은 달 거래를 묶으면 유의성이 사라지고,
상위 4% 거래를 빼면 초과수익이 0이 된다. 게다가 이 조건은 **생존 편향**에 가장 취약하다.
"크게 떨어진 종목을 사서 버티기"의 실패 사례(이후 파산·상장폐지)는 yfinance에 없고, 과거 S&P 500
구성종목의 21%가 빠져 있다. 상장폐지 코인까지 포함된 코인 데이터에서는 같은 방식의 중앙값이 −16~−21%이고,
평균은 2017~2021년 광풍기의 몇 번의 폭등이 만들었다.

## 결론

1. **피보나치 비율 자체에는 특별한 힘이 없다.** 레벨 검증과 규칙 검증 모두 같은 결론이다.
2. **"크게 오른 뒤 눌린 종목"이라는 진입 조건은 미국 주식에서 약한 정보를 담고 있다.**
   1차 익절 도달 확률이 무작위보다 5~10%p 높다. 코인에서는 이 효과가 수익으로 이어지지 않았다.
3. **그러나 규칙 전체(1 이탈 손절 + 단계적 익절)는 같은 기간 SPY를 그냥 보유한 것보다 못하다.**
   진입에서 얻은 우위를 매도 방식이 다 까먹는다.
4. 손절 없이 버티는 쪽은 좋아 보이지만 소수의 대박과 생존 편향에 기댄 결과라 채택할 수 없다.

## 다중 비교 주의

이 문서에서만 20가지 가까운 설정을 시험했다. 이렇게 많이 시험하면 우연히 유의하게 나오는 설정이
생기기 마련이다. 그래서 두 가지 묶음 방식, 비피보나치 대조, 매도 방식 대조, 시기 분할을 모두 거쳐
일관된 것만 결론으로 남겼다. 새로운 변형을 추가로 시험할수록 이 기준은 더 엄격해져야 한다.

## 실전 로그로 확인할 수 있는 크기

1차 익절 도달 확률 차이(약 6%p)는 실전 기록으로 확인 가능한 크기다. 거래당 결과의 표준편차가 약 0.5이므로
대략 (1.96 × 0.5 / 0.06)² ≈ 270건, 같은 달 신호의 상관을 감안하면 그 몇 배가 필요하다.
S&P 500 일봉 +30% 기준 연 150건 안팎이 나오므로 수년의 기록으로 판정할 수 있다.
반면 SPY 대비 수익 우위는 크기가 작아 실전 기록만으로는 확인하기 어렵다(docs/FACTOR_STUDY.md 검정력 절 참고).
