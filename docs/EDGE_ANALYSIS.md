# 전략 엣지 진단 결과

재현: `python scripts/edge_analysis.py --csv trades.csv`

측정 조건: 유니버스 82종목 × 패턴 4종, 2년, 보유 최대 20거래일, 손익비 게이트 1.20,
왕복 비용 0.25% 차감, 보유기간 비중복 독립 신호만 집계, triple-barrier 정산(갭 체결 반영).

---

## 1. 전체 결과 (독립표본 2,018건)

| 항목 | 값 |
|---|---|
| 전략 거래당 평균 순수익 | **+0.131%** |
| 동일 보유기간 QQQ 평균 | **+0.376%** |
| 초과수익 | **-0.246%p** |
| t 통계량 | **-1.37** (95% CI −0.60 ~ +0.11) |
| 통계적 유의성 | 유의하지 않음 |
| 목표가 도달 | 40.8% |
| 손절 이탈 | 56.5% |
| 기간 만료 | 2.7% |
| 평균 보유 | 5.8거래일 |
| 초과수익 플러스 비율 | 43.1% |

평균 보유 5.8일 기준 연환산:

```
전략 +5.9%/년   vs   QQQ 단순 보유 +17.9%/년
```

**결론: QQQ 대비 알파가 없다.** 통계적으로 0과 구분되지 않으며, 점추정은 소폭 마이너스다.

그대로다. 따라서 레짐 게이팅은 구현하지 않았다.

## 4. 다중비교 함정에 대한 경고

종목별로 쪼개면 표본 15건 이상인 75종목 중 **14종목**이 |t| > 1.96을 보인다.
우연히 기대되는 개수는 약 3.8개이므로 종목 간 분산 자체는 실재한다. 그러나 방향이
양쪽으로 갈린다.

```
AMD  +8.50%p (t=+2.79)      MRNA -7.09%p (t=-5.68)
ARM  +3.71%p (t=+2.22)      INTU -3.02%p (t=-3.59)
MU   +3.48%p (t=+2.14)      AI   -4.72%p (t=-3.54)
```

이는 "패턴이 AMD에서 통한다"가 아니라 "2년간 AMD가 좋았고 MRNA가 나빴다"에 가깝다.
표본 17~29건짜리 종목별 t값을 근거로 유니버스를 좁히면, 이 프로젝트가 지금까지
제거해 온 생존 편향과 소표본 과적합을 그대로 다시 들이게 된다.

**전체 t가 먼저 유의해야 한다. 개별 칸의 t는 그 다음이다.**

## 5. 왜 지는가

- 손절 이탈 56.5% vs 목표 도달 40.8%, 손익비 약 1.4
  → 기대값 ≈ 0.408 × 1.4 − 0.565 × 1.0 = **+0.006R**. 비용 차감하면 사실상 0.
- 평균 보유가 5.8일밖에 안 된다. 명목 보유기간은 20일이지만 절반 이상이 1주일 안에
  손절로 끝난다. 즉 **지는 거래는 빨리 끝내고 이기는 거래는 고정 목표가에서 잘라내는**
  구조다. 상승 추세 종목에서 이 조합은 단순 보유에 구조적으로 진다.
- 실제로 진입 후 20일 MFE 중앙값은 +10.5%인데 목표가는 +9.7%에 걸려 있다.
  목표가를 더 올려도 도달률이 떨어져 상쇄된다.

## 6. 권고

1. **진입 패턴 파라미터 튜닝은 권하지 않는다.** 2,018표본에서 t=−1.37이면 임계값
   조정으로 넘길 수 있는 거리가 아니다. 튜닝해서 t를 2로 만들면 거의 확실히 과적합이다.
2. 다음으로 시험할 가치가 있는 것은 **진입이 아니라 청산**이다. 고정 목표가를 없애고
   ATR 추적 손절(`backtester.backtest_trend_following_strategy`가 이미 구현)로 바꾸면
   "이기는 거래를 끌고 가는" 쪽으로 손익 분포가 바뀐다. 같은 진입 신호로 청산만 바꿔
   재측정하는 것은 저비용 고정보 실험이다.
3. 그래도 알파가 안 나오면, 이 도구를 알파 소스가 아니라 **관찰용 스크리너**로 규정하고
   초과수익 지표를 정직하게 표시하는 편이 낫다. 현재 `tracker`는 `avg_excess_return`,
   `excess_tstat`, `alpha_is_significant`를 산출하므로 대시보드에 그대로 노출하면 된다.
