# 피보나치 되돌림 레벨 검증

재현:
```bash
python scripts/fib_level_study.py                          # 기본: 스윙 +20%, 배리어 스윙폭의 15%
python scripts/fib_level_study.py --swing 0.30 --barrier 0.20
python scripts/fib_level_study.py --swing 0.15 --barrier 0.10
```

## 질문

주가가 상승 스윙 이후 되돌림하다 **피보나치 비율(0.382, 0.5, 0.618, 0.786, 0.886, 1.236, 1.31, 1.382, 1.5)**에
닿았을 때, **아무 의미 없는 비율**에 닿았을 때보다 더 잘 반등하는가?

## 방법

- 데이터: S&P 500 과거 구성종목 610개, 2013~2026 수정종가.
- 스윙: 종가 기준 저점에서 +20% 이상 오른 고점. 그 시점까지의 정보만 사용.
- 되돌림 비율 = (고점 − 현재가) / (고점 − 저점). 1보다 크면 출발 저점 아래.
- 반등 판정: 터치 가격 기준 위아래로 같은 폭(스윙 폭의 15%) 배리어를 두고, 60거래일 안에
  위를 먼저 닿으면 반등. 위아래가 같으므로 정보가 없는 자리의 반등 확률은 약 50%.
- 0.30~1.60을 0.02 간격으로 모든 비율에서 똑같이 측정 (터치 이벤트 136,726건).
- **판정은 깊이 보정 비교**: 각 피보나치 비율을 바로 옆(±0.04~0.08) 비율과만 비교.
  신뢰구간은 종목 단위 부트스트랩.

## 결과

| 설정 | 무작위 날짜 | 되돌림 터치 전체 | 피보나치 − 바로 옆 비율 | 판정 |
|---|---:|---:|---:|---|
| 스윙 20%, 배리어 15% | 56.2% | 57.8% | +0.18%p [−0.76, +1.21] | 차이 없음 |
| 스윙 30%, 배리어 20% | 58.0% | 61.2% | +0.65%p [−0.66, +1.90] | 차이 없음 |
| 스윙 15%, 배리어 10% | 54.2% | 55.7% | +0.26%p [−0.62, +1.15] | 차이 없음 |

비율별 바로 옆 비율 대비 차이 (기본 설정):
0.382 +0.4 / 0.5 +0.1 / 0.618 −0.9 / 0.786 +1.7 / 0.886 −0.7 / 1.236 −2.1 / 1.31 −1.0 / 1.382 +3.7 / 1.5 +0.6 (%p)
— 부호가 들쭉날쭉하고 평균은 0 근처.

## 해석

1. **피보나치 비율은 특별하지 않다.** 0.618에서 산 것과 0.60이나 0.64에서 산 것의 반등 확률이 같다.
2. **되돌림 자리에서 사는 것 자체는 무작위 날보다 약간 유리하다** (+1.5~3.2%p).
   이건 피보나치가 아니라 '눌린 곳에서 산다'는 행위의 효과이며, 크기는 작다.
3. **깊이가 반등 확률에 영향을 준다.** 얕은 되돌림(0.3~0.4)은 약 59%, 출발 저점 근처(0.95~1.1)는
   약 54~55%로 낮다. 저점 아래 깊은 구간(1.5 이상)은 표본이 적어 변동이 크다.
4. 반등 확률이 50%가 아니라 54~58%인 이유는 2013~2026년이 대체로 상승장이었기 때문이다.
   무작위 날에 사도 56%가 나온다.

## 분석 과정의 정정

처음에는 피보나치 비율 전체와 대조 비율 전체를 단순 합산해 비교했고, 한 설정(스윙 30%)에서
"피보나치가 특별함"(+1.84%p, 95% 구간 +0.46~+3.31)이 나왔다. 그러나 이는 **깊이 분포 차이가
섞인 결과**였다. 피보나치 집합에는 반등이 잦은 얕은 비율(0.382, 0.5)의 이벤트가 많고, 대조 집합에는
반등이 약한 1.0 근처 비율이 많았다. 깊이를 맞춰 바로 옆 비율과 비교하자 차이가 +0.65%p로 줄고
신뢰구간이 0을 포함했다. 판정은 깊이 보정 비교로만 한다.
